# 早期方案：Mac 常驻 agent（已废弃）

这是这个项目最早的做法：Mac 上跑一个常驻 Node agent，接收抖音链接、调下载脚本取流、用 `ffmpeg` 转成 MP3，再通过局域网 HTTP 接口把音频喂给手机。

**已被 iPhone 原生 App 取代，不再维护。**

废弃原因：

- 需要一个常年开着的 Mac，手机还得和它在同一局域网才能访问
- 要用 launchd 常驻、要管端口、要管 Bearer 令牌，运维成本全落在用户身上
- 多一次 ffmpeg 转码，既慢又有音质损失

留在这里只作为参考：里面能看出「下载 → 转码 → 任务队列」的分层写法，以及 ffmpeg 出 MP3 的参数。真要用请自担风险，接口和手机端早已不对应。

依赖：Node ≥ 18.17，`ffmpeg` 在 PATH 里。用法见 `bin/d2m`。
